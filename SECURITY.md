# Security Policy

Do not report vulnerabilities, credentials, private Figma files, customer data,
or exploitable details through a public issue.

Use GitHub's private vulnerability reporting for this repository. If that channel
is unavailable, contact the repository owner privately through their GitHub profile
and share only the minimum information needed to establish a secure reporting path.

Redact authorization headers, API keys, OAuth tokens, local secrets, proprietary
screenshots, extraction bundles, file URLs, and customer identifiers from all logs
and artifacts.
